# 質問ログの設置

## アップロード前

1. `question_analytics_config.php` を開き、`report_password` の `CHANGE_THIS...` を長く推測されにくいパスワードへ変更します。
2. `suiri.html`、`suiri3.html`、`question_log.php`、`question_report.php`、`question_analytics_config.php`、`question-logs` フォルダを同じ場所へアップロードします。
3. サーバーで PHP 7.4 以上が使えることを確認します。

## 動作確認

1. Web上のゲームを1回開始し、質問カードを開いて質問を1つ選びます。
2. `https://あなたのサイト/配置先/question_report.php` を開き、設定したパスワードでログインします。
3. 「開始ゲーム」「質問を選択」が増えていれば成功です。

`question-logs` はPHPから書き込める必要があります。記録されない場合だけ、レンタルサーバーの管理画面でこのフォルダの書き込み権限を確認してください。一般的には `705` または `755` で動きます。安易に `777` にはしないでください。

可能なら `question_analytics_config.php` の `log_dir` を、公開フォルダ外の絶対パスへ変更するとさらに安全です。初期構成でも、ログファイルはPHPの終了命令と `.htaccess` の両方で直接閲覧を防ぎます。

## 集計の見方

- 表示：その質問カードが選択肢に出た回数
- 選択：実際に選ばれた回数
- 選択率：選択 ÷ 表示
- 平均候補削減率：その質問で候補が平均何％減ったか
- 質問を見て未選択：質問カードを開いた後、山札や宣言へ切り替えた回数

3枚版と4枚版は画面上部で分けて集計できます。CSV保存にも対応しています。

この実装は手札、山札で見たカード、IPアドレス、User-Agent、名前をアプリのログに保存しません。ただし、レンタルサーバー標準のアクセスログには通常IPアドレス等が残るため、サイトのプライバシー表記にはサーバー側アクセスログについても記載してください。
